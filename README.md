# Portafolio web · Nahun Saldivar

Mi portafolio personal: estudiante de Ingeniería de Sistemas e Informática
(Universidad Continental, Cusco, Perú).

🔗 **Demo:** https://nsaldivar.vercel.app

## Qué incluye
- Intro animada con contador y botón para saltarla
- Robot 3D hecho con Three.js que sigue el mouse y reacciona al scroll
- Secciones: sobre mí, proyectos, experiencia, habilidades, educación,
  certificaciones y contacto
- Sitio en español e inglés
- Diseño responsive y animaciones al hacer scroll

## Tecnologías
HTML · CSS · JavaScript · Three.js · Vercel

## Cómo correrlo en local
1. Clona el repositorio.
2. Ábrelo en VS Code y usa la extensión **Live Server** sobre `index.html`.
   (No funciona con doble clic: los módulos JS necesitan un servidor local.)

## Personalizarlo
Todos los datos están en `js/data.js`.
